🚀 איך לפרוס? (3 שלבים פשוטים)
================================================

שלב 1️⃣ - בדיקה מהירה
------------------------
npm run deploy:quick-check


שלב 2️⃣ - פריסה אוטומטית
---------------------------

Windows PowerShell:
  .\deploy-to-ocean.ps1 root@YOUR_SERVER_IP

Linux/Mac/Git Bash:
  chmod +x deploy-to-ocean.sh
  ./deploy-to-ocean.sh root@YOUR_SERVER_IP


או פריסה ידנית:
  npm run deploy:package
  (יוצר קובץ tar.gz להעלאה ידנית)


שלב 3️⃣ - בדיקה בדפדפן
-------------------------
פתח: https://yourdomain.com
בדוק שהכל עובד!
